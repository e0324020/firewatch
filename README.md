The FireWatch Network is an IoT-based forest fire monitoring and alert system developed using Cisco Packet Tracer. The main purpose of this project is to monitor forest areas, detect smoke at an early stage and provide an automated alert and response mechanism to help reduce the damage caused by forest fires.The proposed network is divided into three monitoring areas: Forest A, Forest B and Forest C. Each forest area is connected to a central control network through routers and switches. The central network contains a server and a monitoring computer. The routers are configured with IPv4 addresses and static routing to enable communication between the central network and the forest branches.
A condition named FireAlert-A is configured on the server. When Smoke-A reports an alarm, the rule is designed to change Sprinkler-A's status to ON. A siren can also be integrated to provide an additional warning to nearby people. The FireWatch dashboard provides a central interface for viewing the monitoring areas and their system status.
Cisco Packet Tracer is used to design, configure and simulate the complete network environment. The project demonstrates the integration of computer networking, IoT device communication, server management and automated response concepts.
Overall, FireWatch Network provides a foundation for a smart forest fire monitoring system that can be expanded with additional sensors, monitoring locations and real-world communication technologies in the future.
